# webMCP.jp brand assets (provisional approval)

## Adopted
- Mark: Japan-flag red disc `#BC002D` + symbolic white `{}`
- Wordmark: sumi-strong calligraphy
- Horizontal: smaller mark, wordmark-dominant balance

## Files
- `mark.svg` / `mark.png` — icon only
- `favicon.svg` — site favicon
- `primary.png` — stacked logo
- `horizontal.png` — header / lockup
- `og.png` — Open Graph 1200×630
- `icon-192.png` / `icon-512.png` — app icons

SVG mark is preferred for UI; PNG primary/horizontal preserve calligraphy wordmark.
