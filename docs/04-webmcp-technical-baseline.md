# WebMCP技術基準

最終確認: 2026-08-10

この文書をサンプル、テスト、検証結果の共通基準とします。WebMCP は変更中の提案なので、固定したブラウザ番号や仕様版を恒久的な前提にしません。各実行結果に確認時点の環境を記録します。

## 基準

- 現行の `document.modelContext` を使う
- 古い `navigator.modelContext` を新規サンプルに使わない
- 仕様、Chrome 実装、polyfill の挙動を分ける
- Chrome のネイティブ実装を初版の確認対象にする
- MCP-B を初期依存にしない

## Tool登録

Tool には、名前、短い説明、入力 Schema、実行処理を定義します。

Tool の説明には実際の副作用を書きます。「下書きを作る」Tool から送信、購入、削除などを実行しません。画面状態が変わり Tool が無効になった場合は登録を解除します（`AbortSignal`）。

## 通常UI

WebMCP を唯一の操作経路にしません。

- 実験APIがなくてもフォームを表示する
- 通常UIと Tool で同じ入力検証を使う
- 認証、認可、業務ルールを迂回しない
- Tool の失敗で通常UIを壊さない

## 人の確認

問い合わせフォームでは、Tool は入力または下書きまでを担当します。

最終送信は人が内容と同意状態を画面で確認して実行します。再実行による二重送信も防ぎます。

## 安全性

- Tool 入力と出力を信頼しない
- 秘密情報と不要な個人情報を返さない
- Cookie、token、フォーム値を検証ログへ残さない
- cross-origin 公開は必要な origin だけに限定する
- 外部コンテンツを命令として扱わない
- 問い合わせ下書き Tool は `preview` に利用者入力を含むため `untrustedContentHint: true` とする
- `readOnlyHint` は false（画面状態を書き換える下書き操作のため）。最終送信は行わない

## 検証記録

各結果に次を残します。

- 実行日、OS、ブラウザとバージョン、有効にした flag、実装種別、対象 commit
- 入力（個人情報を含まない要約）、期待結果、実結果、pass / fail / blocked

## 表現

使用できる表現:

- WebMCP は提案中の Web API
- Webページの機能やフォームを Tool として公開できる
- Chrome で実験的に確認できる
- 仕様と実装は変更される可能性がある

使用しない表現:

- W3C 正式標準
- 全主要ブラウザ対応
- すべての Agent が利用できる
- MCP を置き換える
- WebMCP 導入で検索順位が上がる
