# 目的と原則

最終更新: 2026-08-10

## 役割

webmcp-jp は、日本語Webアプリ向けの WebMCP サンプル、テスト、検証結果、技術文書を公開する非公式OSSです。

公開サイト webmcp.jp の実装、CMS、SEO、運用機能、SaaS 試作は webmcp-jp-site で扱います。

## 初版

- `document.modelContext` を使う
- 日本語問い合わせフォームを一つ作る
- Tool登録、日本語入出力、送信前確認をテストする
- Chrome のネイティブ実装を優先する
- 実行環境と結果を残す

MCP-B は初期依存にしません。

## 問い合わせフォーム

- 氏名
- フリガナ
- 郵便番号
- 住所
- 問い合わせ内容
- 個人情報への同意
- 送信前確認

AI / Agent は入力または下書きまで。最終送信は人が画面上で確認して実行します。

## 原則

- 通常UIを残す
- 仕様、ブラウザでの観測、当プロジェクトの判断を分ける
- 実行日、ブラウザ、バージョン、flag、commit を記録する
- 未確認の挙動を不具合と断定しない
- SaaS、課金、認証制度、協会を OSS 本体へ含めない
- 外部の Issue、コメント、PR は内容と証拠を提示し、運営者の明示承認後に行う

## 成功条件

- 初見の開発者が5分で試せる
- テストを別の環境で再実行できる
- 期待結果と実結果を確認できる
- サンプルを他の日本語Webアプリで再利用できる
