# OSS要件

最終更新: 2026-08-10

## 対象

- `examples/`: 動く日本語 WebMCP サンプル
- `tests/`: 再現可能なテスト
- `results/`: 環境情報付きの検証結果
- `docs/`: 実装基準と利用手順

サイト表示、CMS、SEO、認証、課金、GTM、SaaS 機能は対象外です。

## 初版サンプル

- `document.modelContext` で Tool を登録する
- 日本語の氏名、フリガナ、住所、問い合わせを扱う
- 同意状態を確認する
- Tool 実行だけでは最終送信しない
- 実験APIがない環境でも通常フォームを利用できる

## 初版テスト

| テスト | 確認内容 |
|---|---|
| Tool登録 | 対応環境で Tool を登録できる（自動テストは互換スタンドイン＋メタデータ検査） |
| 日本語入出力 | 日本語文字列が欠落や文字化けなく往復する |
| 送信前確認 | Tool 実行だけで送信されない |
| 通常UI | WebMCP がなくてもフォームを利用できる |

## 結果に残す情報

- 実行日、OS、ブラウザとバージョン、有効にした flag、対象 commit
- 期待結果、実結果、pass / fail / blocked

フォーム入力値、Cookie、token、アカウント情報は保存しません。

## 初版の完了条件

- サンプルをローカルで実行できる
- 初版テストを再実行できる
- 環境情報付きの結果がある
- 日本語の手順と短い英語説明がある
- OSS ライセンスと参加方法が明確
- サイト固有コードを含めない
