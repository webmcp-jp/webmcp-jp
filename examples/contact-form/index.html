    2. Chrome の WebMCP 対応環境なら Tool 登録状態が変わります
    3. DevTools コンソール例: await window.__webmcpJpContactForm.executeDraftTool({ name: "山田 太郎", furigana: "ヤマダ タロウ", postalCode: "100-0001", address: "東京都千代田区1-1", message: "資料請求したいです。", consent: true })
